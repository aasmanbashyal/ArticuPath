# Rehearsal v0.3.0 Microsoft Store listing

## Short description

Practice spoken English. Record a take, hear where you stumbled, and try the same passage again.

## Description

Pick a cue card and give yourself a minute to speak. Record your voice, rehearse a presentation with your screen and camera, or read your own script from the teleprompter. Save the take and listen back at your own pace.

Download a speech model to transcribe takes on your PC. Select a timestamp to hear the original audio. If you recorded with a script, compare the transcript with what you meant to say, mark a passage for practice, and try it again. Your session history keeps earlier attempts available for comparison.

Rehearsal runs on Windows 11 x64. Recording and playback work without an account. Optional written feedback uses a local Ollama model or your own OpenAI API key. Your provider may charge for API use.

## What's new

Import your own cue cards from TXT or CSV, check the camera preview before recording, and jump from speaking feedback to the moment in your take. You can edit the coaching prompt and save an OpenAI key in Windows Credential Manager.

## Certification notes

Open Cue cards, select a topic, and choose Record this topic. In Recorder, select Voice, record a short sentence with a microphone, stop, and play the saved take in Sessions. Try the Teleprompter with a short script. Screen recording uses the Windows picker. Recording and playback require no sign-in or API key.

To test transcription, install the recommended speech model in Settings, then transcribe a take. This step needs internet access for the initial model and runtime downloads. Replay the result using its timestamps. OpenAI and Ollama feedback are optional.

The restricted runFullTrust capability launches Rehearsal's Win32 desktop executable. It hosts WebView2, captures and plays media with Windows APIs, writes recordings to the user's chosen folder, and starts a local speech worker for transcription.
