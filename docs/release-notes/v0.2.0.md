ArticuPath 0.2.0 saves recording chunks to disk during capture and makes sessions easier to manage.

- Interrupted takes appear on the Recorder page after reopening the app. Recover a take, download its saved portion, or discard it. Failed saves can be retried without starting the recording again.
- Sessions opens in browsing mode. Choose **Select** to show checkboxes, select individual takes or all visible takes, and delete them after confirmation. **Done** or Escape returns to browsing.
- The calendar has a roomier session panel, simpler take details, and clearer month controls. Narrow windows stack the calendar and session panel. Decorative accent borders and stripes have been removed from these controls and the sidebar.
- Export and restore practice preferences, script drafts, and practice marks from Settings. Recordings and transcripts are backed up separately; API keys are excluded from the practice backup.
- Windows camera recordings now report the full duration of fragmented MP4 files.

Browser and desktop mode share the Rust backend. The frontend is split into smaller modules while keeping the existing recording, transcription, review, cue-card, and teleprompter features. Running from source now requires Rust as well as Bun and the media tools described in [Build from source](https://github.com/aasmanbashyal/ArticuPath/blob/v0.2.0/docs/build.md).

For Windows 11 x64, run [ArticuPath Setup](https://github.com/aasmanbashyal/ArticuPath/releases/download/v0.2.0/ArticuPath-Setup-windows-x64.exe). A standalone ZIP is also included. For Ubuntu 24.04 x64, run `sudo apt install ./articupath_0.2.0-1_amd64.deb`.

Recovery covers chunks already written to disk. A crash can still lose bytes waiting in the browser, and some interrupted media containers need repair before playback. See the [practice guide](https://github.com/aasmanbashyal/ArticuPath/blob/v0.2.0/docs/practice.md) for storage and backup details.
