ArticuPath is now **Rehearsal**. Existing recordings, settings, and downloaded transcription models stay in their current locations.

- Import your own cue cards from TXT or CSV in **Settings → Cue cards**. The preparation timer can start the next take automatically in your chosen recording mode.
- See your camera preview before recording. The preview and the saved video use the same orientation.
- Use **Speaking feedback** to jump to timestamps in a take, edit the coaching prompt, and start another attempt. Rehearsal saves your latest feedback with the take.
- Save an OpenAI API key in the operating system's credential store. You can replace or remove it in **Settings → Feedback**. On Linux, saving a key requires a running Secret Service keyring.
- Follow a four-step English practice session in the README, watch the one-minute studio tour inline, and look up recording and feedback terms in the help section.

## Install

- **Windows 11 x64.** Run `Rehearsal-Setup-windows-x64.exe`, or extract `Rehearsal-windows-x64-standalone.zip` and open `Rehearsal.exe`.
- **Ubuntu 24.04 x64.** Run `sudo apt install ./rehearsal_0.3.0-1_amd64.deb`.

See the [practice guide](https://github.com/aasmanbashyal/rehearsal/blob/v0.3.0/docs/practice.md) for recording and feedback, or [build from source](https://github.com/aasmanbashyal/rehearsal/blob/v0.3.0/docs/build.md).
